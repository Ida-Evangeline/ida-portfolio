# Ida Evangeline D — Purple 3D Portfolio

## Run locally
1. Extract this ZIP file.
2. Open the extracted `ida_purple_3d_portfolio_final` folder in Visual Studio Code.
3. Install the **Live Server** extension by Ritwick Dey if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.

The opening welcome screen now displays Ida's cartoon portrait with purple orbit effects, sparkles, a gentle 3D-style entrance and floating animation. Click **Step into my portfolio** or **Skip intro** to enter the site; otherwise it transitions automatically after a few seconds.

## Files
- `index.html` — portfolio content and welcome intro
- `style.css` — purple theme, responsive layout and animations
- `script.js` — navigation, intro controls and Three.js animation
- `ida-avatar.png` — supplied cartoon portrait
- `resume.pdf` — supplied resume

The site loads Google Fonts and Three.js from CDNs, so an internet connection is needed for those external assets and the 3D sculpture.
